Publicar para TV

Grava uma cópia desta apresentação (mês e filtros atuais) dentro do app publicado. Na TV, abra o link do app com #tv no final: ela passa sozinha, em loop, sem anexar planilhas. Quando você publicar de novo, a TV se atualiza sozinha.

Publicar no GitHub com um clique

O token fica guardado só neste navegador. Crie em GitHub → Settings → Developer settings → Fine-grained tokens, só para este repositório, com permissão Contents: Read and write.

Baixar HTML gera um arquivo index.html que abre direto na apresentação, sem planilhas. Serve para GitHub Pages, servidor da empresa ou pen drive.

Toque ou clique na tela para ver em tela cheia

Gerar vídeo para TV (MP4)

O vídeo usa o mês e os filtros desta apresentação. Grave o arquivo num pen drive e abra no player de mídia da TV, com repetição ligada.
